AURA Quick Setup Guide

Learn how to configure permissions, modules, and commands.

1. Invite & Administrator Rights

For AURA to protect against raids, mute abusers, delete malicious webhook pings, and generate temporary channels, ensure the bot role has Administrator or Manage Roles/Channels permissions.

2. Connect via Web Dashboard

Log in using the ⚡ Discord Login button at the top right. AURA automatically filters servers where you have Administrator rights so you can edit greeting embeds and security toggles in real time.

3. Instant Commands Setup

Use /setup overview in Discord to review active modules. Slash commands sync automatically to your Discord server upon bot startup.
