Central Database Cloud Sync

Cross-environment synchronization between your Bot Host and Render Dashboard.

Connection Status: Connected
Database Engine: MongoDB Atlas
Host Environment: Render / Bot Host

How To Connect Both Environments:

  1. Get a free MongoDB connection URI from MongoDB Atlas.
  2. In your Bot Host (.env), add: MONGODB_URI=mongodb+srv://...
  3. In your Render Dashboard (Environment Variables), add: MONGODB_URI=mongodb+srv://...
  4. Now every setting changed on Render immediately updates the Bot on your Bot Host!

AURA Web & Discord Sync Guide

Learn how settings changed in this web portal immediately reflect on your Discord server.

1. Instant Sync Architecture

Every configuration pane connects directly to the bot's data store and the Discord REST API. When you save announcements or rules, they post immediately to the targeted channel.

2. Reaction Roles Limits

You can attach up to 25 reaction roles per embed. Enable Unique Roles if users can only pick one choice, or enter Restricted Role IDs to require specific prerequisites.

3. Leaderboard Exact Usernames

In strict compliance with server fairness, the XP Leaderboard displays the member's exact Discord username rather than server nicknames.
